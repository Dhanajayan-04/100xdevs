# Week 10 – PostgreSQL & Prisma

This week focuses on learning **PostgreSQL** and **Prisma ORM** with Node.js and TypeScript.

## Topics Covered

* PostgreSQL basics
* Connecting a Node.js application with PostgreSQL
* Writing basic SQL queries
* Working with databases using TypeScript
* Prisma ORM
* Prisma schema and models
* Database migrations
* CRUD operations with Prisma

## Projects

### 1. PostgreSQL Simple

A basic project created to understand how to work with **PostgreSQL directly** from a Node.js/TypeScript application.

**Topics practiced:**

* PostgreSQL database connection
* SQL queries
* Creating and managing tables
* Insert, read, update, and delete operations
* Using PostgreSQL with TypeScript

### 2. Prisma Simple

A basic project created to understand **Prisma ORM** and how it simplifies database operations.

**Topics practiced:**

* Prisma setup
* Prisma schema
* Models
* Database migrations
* Prisma Client
* CRUD operations
* Connecting Prisma with PostgreSQL

## Tech Stack

* Node.js
* TypeScript
* PostgreSQL
* Prisma
* Jest
* Git & GitHub
