# PayTM - Basic Version

![PayTM Demo](src/images/Screenshot.png)

This project is part of my backend development learning journey, built as a beginner-level project to understand the fundamentals of Node.js, Express.js, MongoDB, authentication, and REST APIs.

## Project Overview

The PayTM Basic Version is a simple digital wallet application that allows users to create an account, sign in, view their balance, search for other users, and transfer money between accounts.

It helped me understand JWT authentication, authentication middleware, Express routing, MongoDB with Mongoose, request validation, and MongoDB transactions.

## Features

* User signup and signin
* JWT-based authentication
* Protected routes using authentication middleware
* View account balance
* Transfer money between users
* Search for users
* Update user information
* MongoDB database integration  
* Request validation using Zod

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JSON Web Token (JWT)
* Zod
* Postman

## Usage

To try out the PayTM Basic Version locally:

1. Clone this repository:

```bash
git clone https://github.com/Dhanajayan-04/paytm.git
```

2. Navigate to the project directory:

```bash
cd paytm
```

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

The server will run on `http://localhost:3000`.
