# Week 2 – Async JavaScript & Node.js

This week focused on understanding **asynchronous JavaScript** and getting started with **Node.js**.

## 📚 Topics Covered

### 1. Async JavaScript

The `01-async-js` folder contains exercises and tests related to asynchronous JavaScript.

Topics covered:

* Callbacks
* Promises
* Async/Await
* Handling asynchronous operations
* Promise-based programming
* Writing and testing asynchronous functions

### Folder Structure

```text
01-async-js/
├── easy/
├── medium/
├── hard/
├── tests/
├── .gitignore
├── README.md
├── package.json
└── package-lock.json
```

The exercises are divided into different difficulty levels:

* **Easy** – Basic asynchronous JavaScript concepts
* **Medium** – Intermediate async operations
* **Hard** – Promise-based problems and more complex asynchronous logic
* **Tests** – Automated tests for the solutions

## 2. Node.js

The `02-nodejs` folder contains my introductory Node.js exercises.

* Building a basic Todo server
* Running and testing Node.js programs
